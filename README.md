# x-parser

**ربات تلگرام مانیتورینگ اکانت‌های X (توییتر)**  
پست‌های جدید رو به‌صورت خودکار می‌گیره، به فارسی ترجمه می‌کنه و برات می‌فرسته.

---

## ویژگی‌ها

- مانیتور چند اکانت همزمان
- ترجمه خودکار پست‌ها به فارسی (با Gemini)
- ارسال عکس‌های پست
- ذخیره‌سازی در دیتابیس
- اجرا با یک کانتینر Docker (ساده و پایدار)
- فاصله چک کردن قابل تنظیم (ضد بن شدن IP)

---

## پیش‌نیازها

- Docker
- توکن ربات تلگرام (از [@BotFather](https://t.me/BotFather))
- Auth Token توییتر (از کوکی مرورگر)
