# x-parser

ربات تلگرام برای مانیتور کردن اکانت‌های X (توییتر)  
پست‌های جدید رو می‌گیره، به فارسی ترجمه می‌کنه و برات می‌فرسته.

---

## ویژگی‌ها

- مانیتور چند اکانت همزمان
- ترجمه خودکار پست‌ها به فارسی (با Gemini)
- ارسال عکس‌ها همراه پست
- ذخیره‌سازی در دیتابیس
- اجرا با Docker (ساده و پایدار)

---

## پیش‌نیازها

- Docker
- توکن ربات تلگرام (از [@BotFather](https://t.me/BotFather))
- Auth Token توییتر (از کوکی مرورگر)
